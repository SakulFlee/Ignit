# ignit-cli

Command-line tool for creating and building Ignit projects.

```shell
cargo install ignit-cli
ignit init my-game --template all-in-one
```

See the [Ignit repository](https://forgejo.sakul-flee.de/SakulFlee/Ignit) for
engine usage, templates, and platform setup.
